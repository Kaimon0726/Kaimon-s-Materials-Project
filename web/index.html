MATERIALS INFORMATICS · THERMOELECTRIC TRANSPORT

第一原理計算を、
機械学習で置き換える。

無機半導体の電子・熱電輸送物性を予測する3ステージMLパイプライン。 DFTバンド構造計算とBoltzTraP輸送計算という高コストなワークフローを、 Materials Project の登録データに基づく安価なサロゲートモデルで代替し、 材料スクリーニングを高速化します。

013ステージ設計

バンドギャップ → 輸送物性という物理的因果連鎖に沿って設計。ただし予測値のカスケードは行わず、 各ステージの入力はデータベース登録値のみに固定 — 誤差伝播を断ち、各モデルを独立に評価可能に保ちます。

STAGE 1Eg

バンドギャップ

DFTバンド構造計算の代替。8種の古典的半導体による導入デモ。ここで得た「ギャップが電気的振る舞いを駆動する」という知見が後段の設計原理になります。

代替対象
DFT band structure
STAGE 2S

ゼーベック係数

DFT + BoltzTraP輸送計算の代替。MP登録バンドギャップ(Stage 1の予測値ではない)を特徴量として、約15,000件の半導体で学習。

代替対象
DFT + BoltzTraP
STAGE 3σ

電気伝導率

Stage 2の予測値は使わず、登録量のみから独立に予測。数桁にわたるため log₁₀σ として学習します。

代替対象
DFT + BoltzTraP

03結論 — バンドギャップは効いているか?

SHAP重要度 1位 / 145特徴量

登録バンドギャップは、ゼーベック係数(p型・n型とも)で単独最重要の特徴量。2位に約4倍の差をつけています。小さいギャップがSを急激に抑制する方向性は、バイポーラ伝導の物理と整合します。

電気伝導率でも Top 10

σでは電子数記述子(未充填d状態・p価電子)と密度が支配的で、ギャップは4位/7位の寄与。「ギャップ→輸送」の因果連鎖をSHAPが定量化した形です。

注意事項

  • ターゲットは計算値(GGAバンド構造上のBoltzTraP/CRTA)であり実験値ではありません。GGAはギャップを系統的に過小評価します。
  • σ は緩和時間 τ = 10⁻¹⁴ s の定数近似の下でのみ定義されます。
  • 同一BoltzTraP計算に由来する有効質量 m* は、ターゲット隣接リークとなるため特徴量から意図的に除外しています。
